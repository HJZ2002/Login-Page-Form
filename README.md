🔐 A Simple Login Page — Built With Heart

My first real step into the world of frontend design.
Small in scope, but big in meaning.

This is a clean and simple login page I built entirely from scratch using HTML, CSS, and a touch of JavaScript — not because I had to, but because I wanted to understand how things work.
Every pixel of padding, every hover effect, every button — I thought about it. I tested it. I fixed it. Then I made it better.
It's not a complex app. It won't change the world. But it represents something important to me: the moment I stopped just learning about frontend development and started actually doing it.

💡 What I Learned Building This

How to structure a clean, centered layout from scratch
How to style forms and buttons to feel modern and inviting
How to add social login buttons (Gmail, Facebook, GitHub, LinkedIn) that look real
That the smallest details — spacing, color, shadow — make all the difference


🌱 Why It Matters
Every great developer started somewhere.
This is my somewhere.

Built with curiosity, patience, and a genuine love for making things look good. ☕
